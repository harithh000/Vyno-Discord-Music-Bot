# Vyno Discord Music Bot

Vyno is a high-performance Discord music bot built for stability and clean audio streaming. It features an interactive Web Player, automated voice stability, and server-level customization.

## Quick Links

- **Add Vyno to Server:** https://discord.com/oauth2/authorize?client_id=1400594651609829498
- **Official Support Server:** https://discord.gg/hJ7E6eQX3A
- **Full Commands List:** https://vyno.onl/commands

## Key Features

- **Auto Reconnect:** Automatically reconnects to the voice channel and restores playback state in case of network drops or server restarts.
- **Interactive Web Player:** Real-time queue management, search, and playback controls directly from your browser at vyno.onl.
- **Server Profile Customization (`/botprofile`):** Customize Vyno's avatar and banner specifically for your server (Gold Tier).
- **Button Controls:** Full player control using interactive Discord buttons without needing to type repeated commands.
- **24/7 Mode:** Keeps the bot connected in your voice channel continuously.

## Main Commands

- `/play` - Search and play tracks or playlists from supported URLs.
- `/join` - Connect Vyno to your voice channel.
- `/botprofile` - Set custom server avatar and banner for Vyno.
- `/247` - Toggle 24/7 voice channel persistence.
- `/settings` - Configure audio and server-specific preferences.
